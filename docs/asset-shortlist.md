# Asset Shortlist

Updated: April 9, 2026

## Current Constraint

The current client renders procedural voxel faces and does not yet import external 3D models, textures, or animation data.

That means the best near-term visual wins are:

- build important props directly as voxel geometry in the client
- use external packs as style references and future import targets
- use 2D icon packs for HUD, inventory, crafting, and perk UI before full 3D asset importing exists

## Strongest Style Matches

### Quaternius Cube World Kit

Link: https://quaternius.com/packs/cubeworldkit.html

Why it fits: cube-style characters, enemies, animals, and environment pieces line up closely with the current stylized voxel direction.

Notes: CC0. Official page lists 108 models, animated content, and FBX/OBJ/Blend/glTF support.

### Quaternius Fantasy Props MegaKit

Link: https://quaternius.com/packs/fantasypropsmegakit.html

Why it fits: strong fantasy prop coverage for benches, stalls, books, tools, potions, furniture, and dungeon dressing.

Notes: CC0. Official page says 200+ medieval props with a free portion available.

### Kenney Voxel Pack

Link: https://www.kenney.nl/assets/voxel-pack

Why it fits: good match for voxel-ish UI, item previews, loading screens, recipe icons, and placeholder art direction references.

Notes: CC0. Official page lists 190 files and tags it for items, characters, and tiles.

## Useful UI Candidate

### Skymon Icon Pack Free

Link: https://opengameart.org/content/skymon-icon-pack-free

Why it fits: useful for perks, inventory categories, crafting recipes, status effects, and combat UI.

Notes: CC0. OpenGameArt page says 200+ white PNG icons at 512x512.

## Suggested Next Import Order

1. UI icons first
2. prop kit second
3. full character/environment model import after the renderer has a basic external mesh pipeline
